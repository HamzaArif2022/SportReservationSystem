# 🏟️ SportReservationSystem

## Application de Réservation de Créneaux Sportifs (Terrains)

---

## 📋 Description

**SportReservationSystem** est une application web permettant de gérer les réservations de terrains sportifs pour un complexe sportif. L'application remplace le système papier traditionnel par une solution digitale moderne avec deux rôles principaux :

- **Client** : Consulte les disponibilités, effectue des réservations et paie en ligne
- **Gestionnaire** : Gère les terrains, créneaux, tarifs, et valide les réservations

---

## 🎯 Objectifs du Projet

- Digitaliser le processus de réservation
- Éliminer les doublons et conflits de réservation
- Offrir une visibilité en temps réel des disponibilités
- Permettre le paiement en ligne sécurisé
- Fournir des statistiques et tableaux de bord pour le pilotage

---

## 🏗️ Architecture Technique

### Technologies Utilisées

| Couche | Technologie |
|--------|-------------|
| **Backend API** | ASP.NET Core 8 Web API |
| **Frontend** | HTML5, CSS3, JavaScript (Fetch API) |
| **Base de Données** | SQL Server Express / SQLite |
| **ORM** | Entity Framework Core (Code First) |
| **Authentification** | JWT (JSON Web Tokens) |
| **Documentation API** | Swagger / OpenAPI |
| **Versionnage** | Git / GitHub |
